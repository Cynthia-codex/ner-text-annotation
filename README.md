# Named Entity Recognition (NER) — Text Annotation Project

## Overview
This project demonstrates **Named Entity Recognition (NER)** annotation — identifying and labeling key pieces of information inside text, such as people, organizations, locations, products, and dates.

NER is a foundational NLP task used in resume parsing, search engines, chatbots, and customer data extraction systems.

## What I Did
I manually annotated a set of sentences, tagging each entity with its correct category:

- **PERSON** — names of individuals
- **ORG** — companies, institutions, or organizations
- **LOCATION** — cities, countries, or places
- **PRODUCT** — named products or items
- **DATE** — specific dates or time references

## Why This Matters
Companies rely on NER to:
- Automatically extract key details from resumes, emails, or support tickets
- Power search and recommendation systems
- Structure unstructured text into usable data for AI models

This is different from sentiment labeling — instead of judging *tone*, NER is about correctly identifying *specific facts* inside a sentence, which requires precision and consistency.
